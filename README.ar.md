## 🌟 مميزات المشروع

- 🧵 **ملمس قماشي ثلاثي الأبعاد**: بطاقات وقوائم مضغوطة في نسيج قماشي ثلاثي الأبعاد مع تفاعل ديناميكي مع حركة المؤشر ومصادر الإضاءة.
- 🚀 **صفر مكتبات خارجية (Zero Dependencies)**: مبني بالكامل باستخدام تقنيات الويب القياسية (HTML5، CSS3، ES Modules) دون أي إطار عمل أو حزم CDN.
- 📦 **يعمل بدون إنترنت بالكامل (Offline-First)**: تُحفظ جميع المشاريع والبطاقات والرسومات داخل جهازك محلياً في قاعدة بيانات المتصفح IndexedDB دون إرسال أي بيانات لخوادم خارجية.
- 🖐️ **سحب وإفلات تفاعلي مع حركات FLIP**: إعادة ترتيب مرنة للبطاقات والقوائم باستخدام خوارزمية الفهرسة الكسرية مع انتقالات سلسة.
- 🔊 **مؤثرات صوتية اصطناعية**: أصوات تفاعلية ناعمة يتم توليدها وترددها في الوقت الفعلي باستخدام واجهة برمجة Web Audio API دون تحميل أي ملفات صوتية.
- ⭕ **قائمة دائرية سريعة (Radial Menu)**: قائمة تفاعلية شبيهة بتطبيقات المراسلة الحديثة تظهر بالضغط المطول لتنفيذ الإجراءات السريعة.
- 🖌️ **لوحة رسم وتخطيط مدمجة (Whiteboard)**: لوحة تخطيط متجهات متكاملة تحتوي على أدوات الرسم الحر، الأشكال الهندسية، الأسهم، والألوان.
- 🌗 **سمات متعددة (فاتح، داكن، ونظام الجهاز)**: توافق بصري متكامل مع إمكانية اختيار لوحة الألوان المخصصة (بنفسجي، محيطي، زمردي، دافئ، وردي).
- 💻 **تطبيق حاسوب أصيل (Windows Desktop)**: مثبت مخصص لنظام ويندوز 64-بت يعمل عبر بروتوكول آمن `app://boardly/` لضمان استقرار واستقلالية التخزين.

## 🛠️ كيفية التشغيل محلياً

### المتطلبات
- متصفح حديث (Chrome، Edge، Firefox، Safari).
- بيئة Node.js الإصدار 20 فأحدث (اختياري للتشغيل عبر خادم محلي أو تشغيل الاختبارات).

### خطوات التشغيل
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/MohamedAliShaltoot/Marsam.git
   cd Marsam
   ```
2. تشغيل الخادم المحلي المدمج:
   ```bash
   node server.js
   ```
3. افتح الرابط في المتصفح: `http://localhost:3000`

## ⌨️ اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
| :--- | :--- |
| `/` | فتح شريط البحث والتصفية الفورية |
| `W` | فتح لوحة الرسم والتخطيط |
| `T` | التبديل بين النمط الفاتح والداكن |
| `M` | كتم أو تشغيل المؤثرات الصوتية |
| `Ctrl / Cmd + Z` | التراجع عن آخر إجراء |
| `Ctrl / Cmd + Y` | إعادة تطبيق الإجراء المتراجع عنه |
| `Escape` | إغلاق النوافذ المنبثقة وقوائم الخيارات |
| `?` | عرض دليل اختصارات لوحة المفاتيح |
